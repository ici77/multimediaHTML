Mapas de imágenes HTML

Una misma imagen puede contener distintas zonas interactivas, cada una con su propio enlace.

ÍndiceImágenesSiguiente: audio y vídeo

Qué es un mapa de imagen

Es una imagen con varias zonas clicables. Cada zona funciona como un enlace y lleva a un destino diferente. Es útil cuando la posición aporta información, por ejemplo en planos, ilustraciones educativas o manuales técnicos.

Las tres piezas

  1. <img> muestra la imagen y se conecta con el mapa mediante usemap.
  2. <map> agrupa las zonas con un atributo name.
  3. <area> define forma, coordenadas, enlace y descripción de cada zona.
<img src="favoritos.png" usemap="#favoritos" alt="Cuatro favoritos: ciudad y color">

<map name="favoritos">
  <area shape="rect" coords="0,0,200,200" href="ciudad.html" alt="Mi ciudad favorita">
  <area shape="rect" coords="200,0,400,200" href="color.html" alt="Mi color favorito">
</map>

Formas y coordenadas

  • rect: cuatro valores, x1,y1,x2,y2.
  • circle: tres valores, centroX,centroY,radio.
  • poly: varios pares de coordenadas para dibujar un polígono.

Las coordenadas se cuentan desde la esquina superior izquierda, que es 0,0. Revisa las zonas cuando cambie el tamaño de la imagen.

Accesibilidad y decisión

  • Escribe un alt general en la imagen.
  • Escribe un alt claro en cada area.
  • Comprueba el uso con teclado y ofrece enlaces de texto equivalentes.
  • No dependas solo del color para explicar una zona.

Para un menú o enlaces sencillos es preferible usar enlaces HTML y CSS. Reserva el mapa de imagen para casos donde la posición de las zonas sea importante.
