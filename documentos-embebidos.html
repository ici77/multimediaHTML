Enlazar es la opción más robusta

Para la mayoría de documentos, un enlace claro es la solución más compatible. Indica qué encontrará la persona y si se abrirá en otra pestaña.

Mostrar un PDF dentro de la página

object permite ofrecer contenido alternativo si el navegador no puede mostrar el PDF.

<object data="docs/manual.pdf" type="application/pdf" width="100%" height="600">
  <p>No se puede mostrar el documento. <a href="docs/manual.pdf">Ábrelo aquí</a>.</p>
</object>

Si utilizas embed o object, deja siempre un enlace visible al archivo.

Lista de comprobación

  • El recurso tiene un título o texto de enlace descriptivo.
  • Los enlaces externos que se abren en otra pestaña usan rel="noopener noreferrer".
  • Los iframes tienen title.
  • Los documentos embebidos incluyen una alternativa.
